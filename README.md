# Книжный магазин на Python

Учебный проект в рамках обучения Octagon.

## Описание

Программа для работы с базой данных книжного магазина.
Реализованы две связанные таблицы: books и categories.

## Используемые технологии

- Ubuntu (WSL 2)
- Python 3
- PostgreSQL
- SQLAlchemy
- psycopg2-binary
- python-dotenv
- Visual Studio Code
- Git и GitHub

## Возможности

- Подключение к PostgreSQL
- Создание таблиц
- CRUD для книг и категорий
- Заполнение базы данных
- Вывод списка книг и категорий

## Запуск проекта

1. Создать и активировать виртуальное окружение.
2. Установить зависимости: pip install -r requirements.txt
3. Создать файл .env с параметрами подключения к БД.
4. Заполнить базу: python app/init_db.py
5. Запустить программу: python app/main.py

## Результат

2 категории и 8 книг.
Скриншоты работы программы находятся в папке examples/.
